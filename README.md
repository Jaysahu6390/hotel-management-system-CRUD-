# Hotel Management System

A full-stack hotel management application built using Django, MySQL, REST API, Docker and Celery.

## Features

- User Authentication
- Room Management
- Customer Management
- Booking Management
- Payment Management
- REST API
- Email Notifications
- Docker Support

## Tech Stack

Backend:
- Python
- Django
- Django REST Framework

Database:
- MySQL

Frontend:
- HTML
- CSS
- Bootstrap

DevOps:
- Docker
- Docker Compose
- Gunicorn
- Nginx

## Run Project

Clone repository

Install requirements

Configure .env

Run:

docker compose up --build
